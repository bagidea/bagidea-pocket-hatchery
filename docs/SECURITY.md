## TL;DR

เกมรันบน **สัญญาเดียว** (`phgamecreatr`). กติกาเหล็กมี 2 ข้อ:

1. **ผู้เล่นทำได้แค่กับตัวของตัวเอง** — ทุกคำสั่งเช็คว่า "สัตว์ตัวนี้เป็นของมึงจริงเปล่า" ก่อนทำ
2. **คนที่แต่ตั้งค่าเกม/จ่ายเงินออกได้คือตัวสัญญาเอง** (`phgamecreatr@active`) — ไม่ใช่ผู้เล่นคนไหน

ผู้เล่นโกงไม่ได้เพราะเข้าไม่ถึงปุ่ม admin และของทุกอย่างถูกตรวจเป็นเจ้าของก่อนเคลื่อนไหว.

## ผู้เล่นทำอะไรได้ (ทั้งหมดนี้เฉพาะ "บัญชีตัวเอง + สัตว์ตัวเอง")

| เร่งโตด้วย HATCH | `accelerate` | ตัวของเรา + **ต้องอิ่ม** (กันบายพาสระบบอาหาร) |

## ผู้เล่นทำอะไร **ไม่** ได้ (โกงไม่ผ่าน — เพราะสัญญาตีกลับ)

- ❌ **แตะตัวคนอื่น** — ให้อาหาร / วิวัฒนาการ / เร่งโต / เปลี่ยนชื่อ / เผา / สวมคอสตูม ของสัตว์ที่ไม่ใช่ของตัวเอง → สัญญาตีกลับ `not your creature`
- ❌ **ตั้งค่าเกมเอง** — ปรับราคา / เพิ่มสายพันธุ์ / หยุดเกม / เติมเงินกอง / ถอนเงิน → ตีกลับ `missing authority of phgamecreatr` (เฉพาะตัวสัญญาทำได้)
- ❌ **รับรางวัลซ้ำซีซั่นเดียว** → ตีกลับ `already claimed this season`
- ❌ **สวมคอสตูมปลอม** (template มั่ว) → ตีกลับ `cosmetic template not found` (ดู §คอสตูมด้านล่าง)
- ❌ **ส่งเหรียญปลอมเข้าสัญญา** — สัญญาฟังแค่โอน WAX ของแท้ (`eosio.token`) เท่านั้น เหรียญจากคอนแทรกต์อื่นไม่ถูกประมวลผล → ไม่มีผลข้างเคียงใดๆ
- ❌ **ปลุกสัตว์ด้วย memo มั่ว / จำนวนไม่พอ / ตัวคนอื่น** → ตีกลับทั้งหมด WAX ไม่ถูกหัก
- ❌ **ดูดเงินออกจากกองรางวัล** ผ่านช่องทางผู้เล่น → ไม่มีช่องทางนั้นอยู่เลย

## เงินอยู่ไหน — กัน "เจ้ามือหนีไปกับเงิน" และ "ดูดกองจนหมด"

- **EGG ที่ผู้เล่นจ่าย** (hatch/evolve/breed/unlock/equip) ถูก **เบิร์นทำลายทิ้งจริง** — ไม่ไปตกอยู่กับใคร, ลดอุปทาน
- **กองรางวัล (rewardpool)** = HATCH ที่เติมไว้สำหรับจ่าย claimreward + burncreature
  - ทุกการจ่ายเช็คว่า `กอง ≥ ยอดจ่าย` ก่อน — กองไม่พอยกเลิกธุรกรรม (ผู้เล่นไม่เสียหาย)
  - มาร์ค "รับแล้ว" **ก่อน** หักเงิน (กัน re-entrancy — จุดที่เคยเป็นช่องโหว่คลาสสิก)
- **ถอนเงินออก** (`withdraw`, admin เท่านั้น) เช็คว่าจะถอนแค่ "ส่วนเกิน" = `ยอดในสัญญา − ที่ต้องเก็บไว้ในกอง` → **ดูดกองรางวัลจนหมดไม่ได้** แม้ admin เองก็ตาม

## ใครคุมอะไร (admin powers และขีดจำกัด)

เฉพาะ `phgamecreatr@active` (Poppy ถือกุญแจ) เท่านั้นที่ทำได้ — และทุกอย่าง **ตรวจพยานาหลัง deploy** (ดู negative tests ใน DEPLOY-RUNBOOK):

| พลัง admin | ขีดจำกัด |
|---|---|
| ปรับ config เกม (ราคา/คูลดาวน์/rarity) | เขียนทั้งแถว — ต้องใส่ค่าครบ |
| เพิ่ม/ลบ สายพันธุ์ | ไม่กระทบสัตว์ที่มีอยู่แล้ว |
| หยุดเกมชั่วคราว (`setpaused`) | แช่ทุก action ของผู้เล่น — ใช้ตอนเหตุฉุกเฉิน |
| เริ่มซีซั่นใหม่ / เติมกองรางวัล | ต้องเป็น HATCH ของแท้ |
| ถอนเงินออก | ดูดกองจนหมดไม่ได้ (ดูด้านบน) |

## §คอสตูม (cosmetics) — ตอนนี้ "หลับ" อยู่ เปิดทีหลังได้

หลัง deploy นี้: **สวมคอสตูม (template ≠ 0) จะตีกลับหมด** จนกว่าทีมออกแบบจะสร้าง schema `cosmetics` + template จริงใน AtomicAssets. ถอดคอสตูม (`0`) ใช้ได้ปกติและ **ไม่คิดเงิน**. กลไกนี้คือสิ่งกันโกง — ทำให้แน่ใจว่าไม่มีใครสวม "คอสตูมที่ไม่มีอยู่จริง" ได้. วิธีปลุกฟีเจอร์: ดู **DEPLOY-RUNBOOK-2026-07-20.md §"Cosmetics feature — dormant until schema exists"**.
