05

Slot Engine — Gene → Live Creature

decode gene uint64 → เขียน --critter-* ครบ → inline SVG · default 1:1 · pattern toggle ทำงานจริง · map ครบ 16

All 16 pattern_ids

ตัวตัว/สีเดียวกันหมด — ต่างกันแค่ pattern_id (bits 16–19) → พิสูจน์ group = pid ÷ 4, variant = pid % 4
แต่ละใบ decode pattern_id จริง → patIdx = pid≫2 & 3 (กลุ่ม Stripes/Spots/Hearts/Stars) + variant = pid & 3 (หมุน subtle 0/9/18/27°) · สีตัว/หู/ลาย/ตา ดึงจาก gene ครบทุก token ทุก render

Presets × Tier (glow frame)

เช็ค: Lagoon pid4=Spots · Mystic pid12=Stars · Sunborn pid8=Hearts · Prima pid13=Stars — ถูกต้อง (lab เดิมออกผิดเพราะ & 0x3)
ทำไมถึงดู “ไม่ธรรมดา” ขึ้น: fine-grain texture บนพื้นหลัง + aurora blobs ลอยเบลอ + เงานุ่นุ่ม 2 ชั้น (tight + ambient) + ขอบกระจกมีแสงขอบบน + ปุ่มทองมี glow halo + gradient text หัวเรื่อง. ทุกอย่างดึงจาก tokens.css เดิม (rarity / motion / elevation) จึงเข้าได้กับงาน Monanisa โดยไม่ชน.
