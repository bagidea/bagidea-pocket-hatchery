🔗 How Gene Bits → SVG Colors (The Real Pipeline)

/* uint64 gene — canonical 64-bit layout (matches docs/GENE-SPEC.md) */ bits 0-3: species_id (0-11 = Foxling..Buzzle, 12-15 reserved) bits 4-11: body_hue (0-255 → HSL hue 0-360) bits 12-19: accent_hue (0-255 → HSL hue 0-360) bits 20-23: pattern_type (0-15 → Stripes/Spots/Hearts/Stars…) bits 24-31: pattern_hue (0-255 → HSL hue 0-360) bits 32-35: sat_lvl (0-15 → 40-85% saturation) bits 36-39: bright_mod (0-15 → -15% to +15% brightness) bits 40-43: eye_var (0-15 → eye color palette) bits 44-47: pat_opacity (0-15 → 20-80% opacity) bits 48-51: trait_1 (0-15 → species-specific trait A) bits 52-55: trait_2 (0-15 → species-specific trait B) bits 56-59: trait_3 (0-15 → species-specific trait C) bits 60-63: mutation_flags (bit60=Shiny, bit61=Giant, bit62=Prismatic, bit63=Ethereal) /* The JavaScript decoder (live in this page!) — canonical 64-bit */ function decodeGenetics(gene) { return { species_id: Number(gene & 0xFn), body_hue: Number((gene >> 4n) & 0xFFn), accent_hue: Number((gene >> 12n) & 0xFFn), pattern_id: Number((gene >> 20n) & 0xFn), pattern_hue: Number((gene >> 24n) & 0xFFn), sat_lvl: Number((gene >> 32n) & 0xFn), bright_mod: Number((gene >> 36n) & 0xFn), eye_var: Number((gene >> 40n) & 0xFn), pat_opac: Number((gene >> 44n) & 0xFn), trait_1: Number((gene >> 48n) & 0xFn), trait_2: Number((gene >> 52n) & 0xFn), trait_3: Number((gene >> 56n) & 0xFn), mutations: Number((gene >> 60n) & 0xFn), }; } // Colors computed → CSS variables injected → SVG re-renders instantly

How it actually works: Try the interactive lab above — move any slider and the creature changes color immediately. The same JavaScript decoder runs in production: the client reads genetics (uint64) from the contract's creatures_s table, decodes the bits into HSL colors, injects them as CSS custom properties into the SVG template, and the browser renders the unique creature. One SVG file. Infinite unique creatures. Zero additional storage on-chain.

Breeding: When two creatures breed, the offspring's genes are a cross of both parents: body_hue = avg(parent1, parent2) ± random mutation (±12). Pattern_id is randomly chosen from either parent, with a 5% chance of a new mutation. Pattern overlay is rendered as actual SVG elements (stripes/spots/hearts/stars) — not just a different solid color. The result: every bred creature is visually unique, and rare gene combos produce striking, valuable color patterns.
